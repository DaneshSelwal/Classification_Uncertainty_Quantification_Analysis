# v2.0 patch scripts (reference)

These scripts produced the v2.0 notebook fixes listed in `CHANGELOG_FIXES.md`, starting from the v1
notebooks of commit 237ab65. They have **already been applied**; the notebooks on `version2.0` contain the
result. Keep them as documentation / templates for new generic fixes (`nbpatch.py`: class `NB` with
`rep`, `rep_all`, `save`). Paths inside some scripts point to the original scratch folder.
