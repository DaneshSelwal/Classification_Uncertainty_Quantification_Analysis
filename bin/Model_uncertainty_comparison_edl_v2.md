# Conformal Prediction and Uncertainty Quantification for Evidential Deep Learning (EDL)

> **One-line description:** A pipeline applying distribution-free conformal prediction techniques (SplitCP, CcCP, RC3P) to the Dirichlet expected probabilities generated by the EDL models to produce statistically guaranteed prediction sets.

---

## 1. Overview
While EDL natively outputs Dirichlet concentration parameters, providing an intrinsic measure of uncertainty, downstream decision-making often requires rigorous statistical guarantees. This notebook takes the expected probabilities ($\hat{p} = \alpha / S$) from the trained EDL models and applies Conformal Prediction (CP) to construct prediction sets that contain the true class with a user-specified probability (e.g., $1 - \alpha = 0.95$).

---

## 2. Conformal Prediction Methods

### 2.1 Split Conformal Prediction (SplitCP)
Computes a single global threshold $\hat{q}$ across all classes. 
- **Score Function:** $s_i = 1 - \hat{p}_{y_i}$
- **Threshold:** $\hat{q}$ is the $(1 - \alpha)$ quantile of calibration scores.
- **Set Construction:** Include class $k$ if $\hat{p}_k \geq 1 - \hat{q}$.

### 2.2 Class-Conditional Conformal Prediction (CcCP)
Computes a separate threshold $\hat{q}_c$ for each class $c$ to ensure marginal coverage is achieved for every class independently, which is crucial for imbalanced datasets.

### 2.3 Rank Calibrated Class-Conditional CP (RC3P)
An advanced method that limits the search space by considering the top-$K$ ranked predictions, computing class-wise accuracy matrices, and finding optimal truncated rank limits to minimize average prediction set sizes while maintaining coverage guarantees.

---

## 3. Algorithm

1. **Load Models:** Securely load AlexNet, GFNet, and ViT-UNet with custom Keras objects (`evidence_activation`, `GlobalFilterLayer`, etc.).
2. **Data Split:** Split the independent test pool into calibration and evaluation sets.
3. **Probability Extraction:** Predict $\alpha$ parameters on the datasets and normalize to expected probabilities.
4. **Apply Conformal Methods:** For each model and each CP method, compute $\hat{q}$, build prediction sets, and compute metrics (empirical coverage, average set size).
5. **Full-Scene Inference:** Generate dense spatial maps showing prediction sets and identifying "uncertain" pixels (where set size > 1).

```python
def normalize_probs(prob, eps=1e-12):
    prob = np.clip(prob, 0.0, 1.0)
    rs = prob.sum(axis=-1, keepdims=True)
    return prob / rs
```
Ensures numerical stability when working with expected probabilities derived from Dirichlet $\alpha$.
